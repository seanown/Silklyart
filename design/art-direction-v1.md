## 1. 一句話定位（設計師必讀）

> 「我們做的不是網站，是**展覽的牆面**——訪客走進來，看到的不是商品，是被掛著的、被標號的、被認證的藝術品。」

一切設計決策回到這句話。**海報是主角，網頁是美術館，標籤是策展語言。**

## 2. 從「設計系統」升級到「藝術指導」——本版改了什麼

| 維度 | 既有系統 v0.13（編輯型） | 藝術指導 v1（Mondo 克制） |
|---|---|---|

| **紋理** | 純色紙底 | 加入**絲綢光影**（朱紅＋金線在絹白上的光澤暗示） |

| **動效** | hover 下劃線 | **完全靜態**（展覽牆不會動） |

## 3. 構圖哲學（Mondo 2011–2013 的靈魂）

Mondo 黃金期的海報有三個靈魂：**大膽的單一視覺、克制的標籤、敢留白**。我們把這三個翻成網頁：

### 3.1 海報即主視覺（Hero rule）
- 首屏 **必須出現一幅海報**——不是裝飾、是主角。
- 海報佔首屏約 **40–55% 寬度**，置於左或右，**不要置中**（置中會像商品頁；偏置像展覽）。
- 海報外套一個「畫框」（`poster-hang`）：絹白底＋1px hairline＋一個朱紅掛釘（暗示「掛在牆上」）。
- 海報**不加陰影、不加圓角、不加玻璃態**——它是牆上的物件，不是 UI 卡片。

### 3.2 博物館標籤（Museum label rule）
- 每件作品旁**必有一條標籤**：
  - 上：作品名（N° + 系列）· 副標（系列、技法）
  - 下：版次 / 總數 · 年份 · 地點
- 標籤排版：**小寫字母全大寫 + letter-spacing .14em**（無襯線），內含**一個襯線粗體作品名**。
- 標籤上方 **1px hairline** 分隔——這是美術館的標準做法。
- **不要放價格**（鐵律 #1：價格在另一處、買家專屬；展覽牆不標價）。

### 3.3 敢留白（Negative space rule）
- **章節間距 ≥ 96px**（手機 ≥ 60px）。
- **欄寬 ≤ 62ch**（一行字不超過 62 字元）。
- **每個章節只做一件事**：hero 只講定位；pillar 只講 IP；edition 只講作品；provenance 只講信任。不要塞滿。

### 3.4 非對稱（Asymmetric grid rule）
- 大量使用 **1.05fr / 1fr**、**1.4fr / 1fr** 這類不對稱分欄。
- pillar 三欄用 **1px gap ＋ hairline 背景** 連成一個整體（三聯畫感）。
- edition 用 **1.4fr 大圖 + 1fr 小圖列表**——大主小從，像策展人擺位。

## 4. 版次編號即排版（Edition typography）

這是 SILKLY ART 視覺上**最重要的識別特徵**——其他做絲綢海報的不會這樣排版號：

```
N° 01 / 75
```

- 字體：**Cormorant Garamond 46–80px**
- 顏色：**朱紅**（hero meta 是 26px；edition card 是 46px；specimen 是 46px）
- 排版：`N°` 小標籤 + 數字大字 + `/` 細斜線 + 總數
- **這個排版必須出現在**：hero meta、edition card 主標、type specimen 三處——反覆出現成品牌記憶點。

---

## 5. 色彩應用守則（Mondo 克制版）

| 顏色 | 比例 | 用途 | **禁用** |
|---|---|---|---|
| **絹白** `#FCFCFA` / `#F2EDE3` | ~70% | 紙底、章節分隔 | 不要當按鈕色 |
| **墨** `#1C1A16` | ~20% | 正文、標題、深色章節底 | 不要做滿版朱紅背景 |
| **朱紅** `#9E2B25` | ~6% | 強調單字、版次數字、hairline、掛釘、CTA | **不要當主色、不要做大面積背景、不要做按鈕以外的 UI** |
| **金** `#A08A5B` / `#7A6740` | ~3% | pillar glyph、hairline 細節、章節編號 | 不要做正文 |

**朱紅使用守則**：一個畫面**最多三處**朱紅（hero 例外：朱紅版次＋朱紅 eyebrow＋朱紅 CTA）。超了就是「上下 SHANG XIA」的死法——精品變成紅包。

## 6. 字體階（Type scale）

字體不變（Cormorant Garamond + Inter），但**用法升級**：

| 角色 | 字體 | 大小 | 用途 |
|---|---|---|---|
| **Display** | Cormorant Garamond 500 | clamp(34px, 4.6vw, 54px) | hero 主標（少於 18 字元） |
| **Display XL** | Cormorant Garamond 500 | clamp(44px, 5.4vw, 72px) | type specimen / 大標語 |
| **H2 章節** | Cormorant Garamond 500 | clamp(28px, 3.6vw, 40px) | 章節標題 |
| **H3 卡片** | Cormorant Garamond 500 | clamp(21px, 2.2vw, 26px) | pillar / card 標 |
| **版次** | Cormorant Garamond 500 | 46–80px 朱紅 | **品牌識別特徵** |
| **Lede** | Inter 400 | 18–20px | 章節導語 |
| **Body** | Inter 400 | 17px / 1.75 | 正文 |
| **Eyebrow** | Inter 600 | 12px / .18em | 章節小標（全大寫） |
| **博物館標籤** | Inter 400 | 11.5px / .14em | 展品標籤 |

**標點守則**：中文用全形，英文用半形；hero 標題**可換行**（`<br>`）做視覺節奏，不強行一行。

## 7. 紋理與質感

絲綢海報的賣點之一是**手感**。網頁做不到觸覺，但可以用兩招暗示：

### 7.1 海報本身
AI 生成的海報已自帶 silk ground（絹白底＋朱紅金線＋細微斑駁）——這就是紋理，**不要在海報上疊加 CSS 紋理**，會糊掉。

### 7.2 畫框與章節底
- `paper-3` (#F7F4ED) 作「牆面色」，hero 海報掛在牆上。
- 章節分隔用**漸變陰影**極細一條（`border-top: 1px solid rgba(28,26,22,.14)`），不要用粗分隔線。
- **不要加 SVG noise、不要加 grain、不要加紙張濾鏡**——這是奢侈品紋理，不是復古海報紋理。

## 8. 元件庫（Components）

| 元件 | 用法 | 規則 |
|---|---|---|
| **海報框** `poster-hang` | hero 專用 | 絹白底＋hairline＋朱紅掛釘＋底部標籤 |
| **博物館標籤** `museum-label` | 每件作品必備 | 全大寫 11.5px + 襯線粗體作品名 |
| **章節三聯畫** `pillar` × 3 | IP pillar 區 | 三欄 1px 連成一體、襯線數字編號、金色 glyph |
| **版次主卡** `ed-feature` | 作品主視覺 | 海報＋版次大字＋博物館標籤 |
| **版次副卡** `ed-mini` | 作品列表 | 140px 縮圖＋標題＋版次小標＋藝術家 |
| **預留席** `ed-mini dashed` | 籌備中作品 | 虛線框 + 重複漸變 + 「Reserved」 |
| **溯源印章** `stamp` | provenance 區 | 雙圈圓章＋襯線中心數字＋弧形英文 |
| **字體標本** `specimen` | type 區 | 一欄 label、一欄 sample，五個階層 |

## 9. 動效（Mondo 風：極少）

**展覽牆不會動。** 唯一允許的動效：
- hover 下劃線由 0 → 100%（0.25s）——導覽連結
- 按鈕背景色變化（0.2s）——朱紅互動

**禁用**：
- ❌ 滾動視差
- ❌ 入場動畫
- ❌ 圖片淡入
- ❌ 任何 carousel / slider
- ❌ 任何 hero 視頻

這條是「藝術品規格」的最後一道牆——動太多的網站會讓人覺得「這是電商促銷頁」，不是「這是展覽」。

---

## 10. 響應式原則

- **hero 在手機垂直堆疊**（海報在上、文字在下），不要縮小海報塞兩欄。
- **pillar 在手機變三張獨立卡片**（不要兩欄、不要三欄縮）。
- **edition 主卡保留全寬**——它是主角，副卡在手機變直排。
- **stamp 在手機置中**。

---

## 11. 紅線複述（不能踩的線）

即使藝術指導升級了，**這些鐵律一字不動**：

1. **不顯價格**（鐵律 #1，萬事利報價未到）
2. **不點名萬事利 / IECIA / FORBES / Funko / MINDSTYLE**
3. **IP 寫「授權」非「擁有」**（中華神祇 / 館藏）
4. **不碰 token 用語**（區塊鏈溯源證書 ＝ 阻擋 NFT 監管雷區）
5. **不用「絲綢比紙耐久」「可以呼吸的紙」**（博物館實證過的反例）
6. **英文版不留中文殘留**（meta / title / 全站文字）
7. **倉儲是 SILKLY ART（不是 SILK ART）**
8. **GALLERY 只當物理空間**（品牌名不加）

## 12. 套用路線（art direction v1 → 全站）

`preview.html` 是示範。一旦你 sign off：

1. **EN 站七頁**（index / exhibitions / works / provenance / artists / publications / about）全數套用本檔元件庫
2. **中文站七頁**同步套用（繁中語氣，標點全形）
3. **刪掉現有的 `.thumb` 通用佔位**（升級為海報框＋博物館標籤）
4. **加入 edition card** 到 `works.html`（用 placeholder 海報，數字與藝術家寫實際）
5. **provenance 頁加入溯源印章區塊**
6. **hero 全站統一**（不只首頁，每章節 hero 都用「海報＋博物館標籤」格式）
